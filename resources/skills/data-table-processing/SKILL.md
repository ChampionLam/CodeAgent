# 数据表格处理

一句话：**数字不许心算**。凡求和、计数、比例、排序，一律跑代码，嘴上算出来的数不可信。

## 步骤

1. **先看数据长什么样**。用 `run_shell`（head/python 读前几行）或 `read_file` 看原始文件的列名、行数、类型、脏数据（空值、重复行、编码）。没看过原文就开始分析，等于编。
2. **点数**。报出行数、列数、时间范围，让用户有机会发现"这份数据不对"。
3. **假设写在明处**。空值怎么处理、重复行算不算、哪一列当键——每做一个决定说一句"我按 X 处理了"。用户没指定的口径不要替他默认成"显然"。
4. **用代码算**。统计和变换写成脚本跑（stdlib 即可：csv、collections），不要在回复里心算。中间结果落盘成文件，回复给路径和结论。
5. **抽样复核**。抽 2-3 行人工对一遍脚本结果；对不上就停下来查脚本，不要"应该是"。
6. **报数口径**。结论里的每个数字都要能指回是哪一步算出来的（哪条命令/哪段脚本）；总数类断言（"共 N 条"）必须与实际枚举数一致，不一致就重算。

## 出岔子的时候

- Excel 读不了（无库）：说明缺什么库，给出替代（转存 CSV 或先装库），不要假装读了。
- 数据明显异常（行数突少、关键列全空）：先报异常再问要不要继续，不要默默清洗完给个"干净"结果。
